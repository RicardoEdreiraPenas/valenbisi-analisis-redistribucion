# Datos de Valenbisi

Rama de datos del proyecto [valenbisi-analisis-redistribucion](https://github.com/RicardoEdreiraPenas/valenbisi-analisis-redistribucion).

Cada 15 minutos GitHub Actions guarda aquí el estado de las 273 estaciones en `datos/AAAA-MM-DD/HHMMSS.csv.gz` (hora local de València).

Fuente: [ValenBisi Disponibilidad](https://opendata.vlci.valencia.es/dataset/valenbisi-disponibilitat-valenbisi-dsiponibilidad), Ajuntament de València, licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.es).
